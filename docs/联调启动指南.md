# 本地联调启动指南

应用源码位于 `D:\ai\Demo\RAG\upstream\RagentAI`。本指南描述本地开发启动方式；不要将示例凭据用于公网部署。

## 依赖

- JDK 17、Node.js/npm、Python（文档解析器需要）。
- MySQL、Redis、Milvus 和 S3 兼容对象存储 RustFS。
- DeepSeek 聊天 API Key；百炼 Embedding API Key（文档向量化需要）。
- MCP Server 可选，默认配置地址为 `localhost:9099`。

## 启动基础服务

```powershell
cd D:\ai\Demo\RAG\upstream\RagentAI
docker compose -f resources/docker/milvus-stack-2.6.6.compose.yaml up -d
docker compose -f resources/docker/milvus-stack-2.6.6.compose.yaml ps
```

Compose 默认将 MySQL 映射到宿主机 3307，Redis 为 6379，Milvus 为 19530，RustFS 为 9000/9001。首次创建 MySQL 数据卷时会运行 `resources/database` 中的初始化脚本。本地 Compose 含开发用默认凭据；不要直接用于公网环境。

## 配置并启动后端

在 PowerShell 会话中设置变量（只在本机替换占位符，不要把真实值贴入文档或提交）：

```powershell
$env:MYSQL_HOST = "127.0.0.1"
$env:MYSQL_PORT = "3307"
$env:MYSQL_USERNAME = "root"
$env:MYSQL_PASSWORD = "<本机数据库密码>"
$env:REDIS_HOST = "127.0.0.1"
$env:REDIS_PORT = "6379"
$env:REDIS_PASSWORD = "<本机 Redis 密码>"
$env:MILVUS_URI = "http://127.0.0.1:19530"
$env:DEEPSEEK_API_KEY = "<DeepSeek Key>"
$env:BAILIAN_API_KEY = "<百炼 Key>"
```

在应用仓库根目录执行：

```powershell
cd D:\ai\Demo\RAG\upstream\RagentAI
./mvnw.cmd -pl bootstrap -am -DskipTests install
./mvnw.cmd -pl bootstrap spring-boot:run
```

后端 API 默认地址为 `http://localhost:9090/api/ragent`。模型密钥缺失时，对应的聊天或向量化请求无法成功。

## 启动前端

另开 PowerShell：

```powershell
cd D:\ai\Demo\RAG\upstream\RagentAI\frontend
npm install
npm run dev
```

访问 `http://localhost:5173/login`。用户对话页面为 `/chat`，知识库后台为 `/admin/knowledge`，系统设置为 `/admin/settings`。`/ui-preview` 仅展示静态演示数据。

## 功能联调顺序

1. 登录管理端并创建知识库。
2. 上传文档，检查解析、切片、向量化和索引状态。
3. 进入用户对话页选择该知识库提问，检查回答和来源引用。
4. 删除测试文档后再次提问，确认删除内容不再出现在检索结果中。

端到端流程依赖数据库、向量服务、对象存储和模型 API。没有真实模型凭据时，不要将模型调用结果视为已验证。
