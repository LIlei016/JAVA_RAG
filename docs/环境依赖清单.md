# 运行依赖与发布准备

此清单说明项目运行所需组件，不代表当前机器的实时安装/健康状态。

## 必需组件

| 组件 | 用途 | 配置入口 |
|---|---|---|
| JDK 17 | Spring Boot 后端 | `JAVA_HOME` |
| Node.js/npm | React 前端 | `upstream/RagentAI/frontend` |
| MySQL | 用户、知识库、文档、会话等业务数据 | `MYSQL_*` |
| Redis | 缓存和协调 | `REDIS_*` |
| Milvus | 向量索引和相似检索 | `MILVUS_URI` |
| RustFS/S3 | 上传文件存储 | `RUSTFS_*` |
| DeepSeek API | 问答生成 | `DEEPSEEK_API_KEY` |
| 百炼 Embedding API | 文档和问题向量化 | `BAILIAN_API_KEY` |
| Python | MarkItDown 文档解析能力 | `MARKITDOWN_PYTHON_PATH` |

Docker Desktop 可用于本机启动 MySQL、Redis、Milvus 和 RustFS，Compose 文件位于 `upstream/RagentAI/resources/docker/`。MCP Server 当前为可选能力。

## 发布前检查

- 生产数据库和缓存使用独立账号及强密码，关闭不需要的公网端口。
- API Key 通过部署 Secret/环境变量注入；不得写入 `.env`、源码、文档、镜像层或 CI 日志。
- 替换初始化管理员密码、数据库/Redis/RustFS 开发凭据，并检查访问控制与 HTTPS。
- `upstream/RagentAI/.env.example` 仅作变量名模板，不应放真实密钥。
- 保留 `upstream/RagentAI/LICENSE`、版权头和第三方依赖许可证。
- 提交前检查 Git 状态、完整差异及忽略规则；对曾公开的密钥进行撤销和轮换。
