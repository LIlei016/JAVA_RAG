# 企业知识库问答系统：项目说明

## 项目概览

系统提供用户知识库问答和管理员知识库管理。管理员上传资料后，后端解析并切分文本，调用 Embedding 服务生成向量并写入 Milvus；用户提问时，系统检索相关内容，组织证据和会话上下文后调用 DeepSeek 生成流式回答。

## 功能和路由

- `/login`：登录。
- `/chat`：用户选择知识库并进行多轮流式问答，查看回答来源和会话历史。
- `/admin/knowledge`：管理员维护知识库和文档，查看导入状态。
- `/admin/settings`：查看系统模型配置状态；Key 不返回浏览器。
- `/ui-preview`：纯前端交互预览，使用演示数据，不调用后端 API。

## 架构与技术

React/TypeScript/Vite 前端通过 REST/SSE 访问 Spring Boot 3.5、Java 17 后端。MySQL 保存用户、知识库、文档及会话数据；Redis 支持缓存和协调；Milvus 保存向量并执行相似度检索；RustFS 提供 S3 兼容对象存储。Apache Tika 和 MarkItDown 处理上传文件。

模型配置默认使用 DeepSeek 聊天模型（`DEEPSEEK_API_KEY`）和百炼 `text-embedding-v3`（1024 维，`BAILIAN_API_KEY`）。聊天与 Embedding 是两种职责；换 Embedding 模型或向量维度时，需要迁移或重建向量集合。

## 本地启动

1. 安装 JDK 17、Node.js/npm、Python 和 Docker Desktop。
2. 在仓库根目录启动依赖：

   ```powershell
   docker compose -f resources/docker/milvus-stack-2.6.6.compose.yaml up -d
   ```

3. 在当前 PowerShell 会话设置 `DEEPSEEK_API_KEY` 和 `BAILIAN_API_KEY`，并按本地情况设置 `MYSQL_*`、`REDIS_*`、`MILVUS_URI` 环境变量。不要将真实值写入或提交 `.env`。
4. 在仓库根目录运行后端：

   ```powershell
   ./mvnw.cmd -pl bootstrap -am -DskipTests install
   ./mvnw.cmd -pl bootstrap spring-boot:run
   ```

5. 在另一个终端启动前端：

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

后端 API 默认位于 `http://localhost:9090/api/ragent`，前端默认位于 `http://localhost:5173`。Compose 中的开发凭据只供本机测试，不可用于公网部署。

## API Key 与发布安全

- Key 仅从后端进程环境变量或部署 Secret 注入，禁止放进前端变量、源码、README、截图或提交记录。
- `.env` 和 `.env.*` 已加入忽略规则；示例配置文件可以提交，但只能使用占位内容。
- 管理员、MySQL、Redis、RustFS 的开发凭据必须在部署前替换，服务只开放必要端口并配置 HTTPS。
- 曾在对话中发送过的 API Key 应在对应服务商控制台撤销并重新生成。
- 发布前检查 `git status --short`、完整 diff、忽略规则及待提交文件；保留 `LICENSE` 和版权/第三方许可证声明。

## 测试边界

单元测试位于 `bootstrap/src/test`。构建或单测不等于端到端问答通过；完整验证需要数据库、Redis、Milvus、对象存储可用，并配置有效模型 Key。`/ui-preview` 是演示页，不用于验证真实 API。
